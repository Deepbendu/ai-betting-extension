# 🧠 AI-Powered Betting Assistant – Chrome Extension

A smart, lightweight Chrome Extension that uses AI to analyze sports betting odds, spot arbitrage opportunities, and offer intelligent bet suggestions — all inside a floating calculator panel injected directly into any betting website.

> Designed for real-time use. No backend. No clutter. Just faster, smarter betting.

---

## 🚀 Key Features

### 🎯 Mode 1: Arbitrage Calculator
Leverages odds discrepancies between bookmakers to spot **risk-free betting opportunities**. Helps users:
- Detect flaws in the bookie system
- Calculate exact stake split across outcomes
- Guarantee a fixed profit, regardless of the match result
- Get an **unfair advantage** by backing both teams with the right proportions

### 🤖 Mode 2: Bet Possibility Analyzer *(AI-Powered)*
Uses AI (DeepSeek/OpenAI) to analyze upcoming matches:
- Accepts team names with odds OR a manual match description
- Outputs **short, crisp, point-wise analysis**
- Based on **live or upcoming matches only** (ignores outdated/historical stats)
- Built-in reset and toggle options for smooth experience

### 🔄 Mode 3: Multi Bet Placer *(Coming Soon)*
Future update will allow users to:
- Enter multiple bet slips
- Calculate combined payout probability
- Optimize risk across multi-leg bets

---

## 💡 Why a Chrome Extension (Not a Website)?

Most betting decisions are made **live on websites or betting apps**. Instead of forcing users to switch tabs or apps, I chose to:
- Inject a floating panel **directly into any webpage**
- Provide **real-time, on-the-spot** calculations
- Deliver a fast, distraction-free experience
- Work in sync with user behavior — right where the bets happen

This gives bettors an **immediate edge** without interrupting their flow.

## ⚙️ How It Works

- Built using **HTML, CSS, JavaScript**
- Injects a floating panel using Chrome’s **content scripts**
- AI analysis powered by **DeepSeek/OpenAI APIs**
- Fast and lightweight — no backend, no hosting needed
- Simple user interface with mode toggle and reset options

---

## 🧱 Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **AI Integration**: DeepSeek / OpenAI APIs
- **Extension API**: Chrome (Manifest V3, content scripts)
- **Rendering**: `marked.js` for clean output formatting
